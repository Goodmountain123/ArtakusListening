오디오 출력 설정

관리자 탭의 음악을 이 탭에서 받아 선택한 스피커로 전달합니다. Chrome 또는 Edge 데스크톱에서 사용하세요.

HDMI 디스플레이, 내장 스피커, Bluetooth 스피커 등을 컴퓨터에 먼저 연결하세요. 브라우저에 따라 장치 목록을 표시하려면 마이크 접근 권한이 필요할 수 있습니다. 이 경우 마이크는 목록 확인 직후 종료되며, 녹음하거나 전송하지 않습니다.

연결되지 않음

  1. 관리자 화면의 ‘이 화면 소리 끄기’는 해제하고, 송출 화면의 소리는 끄세요.
  2. 위에서 출력 장치를 선택한 뒤 ‘관리자 탭 오디오 연결’을 누르세요.
  3. 브라우저 공유 창에서 관리자 Chrome 탭을 선택하고 ‘탭 오디오 공유’를 켜세요. 이 설정 탭이나 전체 화면을 선택하지 마세요.
  4. 이 설정 탭을 닫지 말고 관리자 화면에서 평소처럼 재생하세요.

오디오는 이 컴퓨터 안에서만 전달되며 녹음·저장·서버 전송하지 않습니다. 연결 해제 시 원래 탭의 시스템 기본 출력이 복원됩니다. Bluetooth 및 탭 캡처에 따른 지연이 있을 수 있습니다.
