# THE LISTENING PARTY

리스닝 파티용 웹앱. Cloudflare Worker 하나로 돌아간다.

| 주소 | 화면 |
|---|---|
| `/` | 참가자 — 세션별 곡 목록(공개 전 곡은 잠김), 지금 곡, 곡 상세·별점·댓글 |
| `/admin/` | 관리자 — 곡 불러오기, 세션 편성·순서, 곡 정보, 큐포인트, 가사 싱크, 배경 영상, 재생 |
| `/screen/` | 송출 — 곡 정보·해설, 댓글 한 줄, 가사 5줄, 큐 카운트다운, 배경 영상, 참가자 반응 이모지 |

## 관리자 사용 흐름

1. **전체 곡** 탭에서 YouTube 재생목록을 불러오거나, 영상 URL로 한 곡씩 추가
2. 곡을 체크하고 세션을 골라 **에 넣기** (Shift+클릭으로 범위 선택, 「미배정만 선택」)
3. **행사 순서** 탭에서 ⋮⋮를 끌어 순서 변경 (세션끼리도 이동). 세션 이름·설명 편집
4. 곡을 열어 곡 정보 입력, 타임라인을 클릭해 큐포인트 추가
5. 재생 — 재생을 시작한 곡은 참가자 앱에 자동 공개. 「세션 안에서 연속 재생」이 켜져 있으면 세션 마지막 곡까지 이어서 재생하고 멈춤. 다음 세션은 ⏭

## 송출 화면

- 같은 컴퓨터: 관리자 화면의 「송출 화면 ↗」 (관리자 창이 직접 넘겨줌)
- 다른 컴퓨터: 「송출 링크 복사」로 받은 `/screen/?k=송출키` 링크 (서버를 거쳐 따라감). 송출 키는 관리자 토큰과 별개이고, 「행사 ▾ → 송출 링크 바꾸기」로 예전 링크를 끊을 수 있음
- 곡 공개 전 정보·가사·큐는 송출 키를 가진 화면에만 가고 참가자에게는 가지 않음
- 소리: 송출 화면에 숨은 YouTube 플레이어가 관리자 재생 위치를 따라감 (송출 링크로 연 화면은 기본 켬, 같은 컴퓨터 창은 기본 끔, S 키로 전환, 처음 한 번 클릭 필요). 관리자는 「이 화면 소리 끄기」
- F 또는 더블클릭 = 전체화면, ←/→ = 가사·카운트다운 싱크 ±0.1초 (블루투스 지연 보정, 이 컴퓨터에 기억)
- 배경 영상은 서버에 저장(1.5MB 조각, 탐색용 Range 지원). 올린 컴퓨터에는 사본도 남겨 인터넷이 끊겨도 재생
- 관리자 화면이 닫히면 서버의 지금 곡 정보·댓글만 보이고 가사·카운트다운은 숨김

## 저장

- 행사 하나 = JSON 하나 (곡 목록, 곡 정보, 세션 구성·순서, 큐포인트)
- 관리자 토큰이 있으면 서버에 행사별로 자동 저장. 「행사 ▾」에서 열기·새 행사·파일 내보내기/가져오기
- 행사 이름을 바꾸면 새 이름으로 따로 저장(복제)
- 다른 기기에서 먼저 저장된 버전이 있으면 덮어쓰지 않고 멈춤 → 「행사 ▾」에서 선택

## 참가자에게 가는 정보

- 세션: 이름, 설명, 곡 수 (곡 제목은 공개 전까지 서버에도 없음)
- 곡: 제목, 아티스트, 앨범, 연도, 곡 해설, 관련곡
- 가지 않는 것: 선정 이유, 큐포인트, 타임코드
- 별점·댓글·답글·좋아요는 공개된 곡에만 가능. 댓글은 5초에 1개로 제한
- 댓글은 좋아요 순 상위 5개 + 더보기, 답글은 한 단계만(접힌 상태로 표시)
- 「공개 초기화」는 공개 목록·별점·댓글을 지움 (리허설 후 사용). 세션 구성은 유지

## 폴더 구조

```
public/index.html        참가자 화면
public/admin/index.html  관리자 화면
public/vendor/           끌어서 순서 바꾸기 라이브러리 (SortableJS)
src/index.js             서버 (API + 실시간 연결 + 저장)
wrangler.jsonc           Cloudflare 설정
```

## 처음 배포하기

1. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Import a repository** → 이 레포 → Deploy
2. Worker → **Settings** → **Variables and Secrets** → Secret `ADMIN_TOKEN` 추가
3. `https://<worker 주소>/admin/` 접속 → 오른쪽 위에 토큰 입력

이후 GitHub에 push하면 자동으로 다시 배포된다.

## 내 컴퓨터에서 돌려보기 (선택)

```
npm install
echo ADMIN_TOKEN=test > .dev.vars
npm run dev
```

→ http://localhost:8787/admin/
